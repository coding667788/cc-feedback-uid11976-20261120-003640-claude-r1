为合成的园区访客预约开发离线通行裁定器。访客只有在其预约有效、陪同人持续在岗且目的区域接受相应资格时才能通行。使用 Windows 原生 Python 3.12、标准库和 SQLite，不调用真实门禁、操作系统管理接口或外部服务。提供 load、coverage、admit、verify 命令。

预约固定访客、区域、名额上限和一个整数分钟区间 [start,end)。在岗记录和区域资格也用半开区间，陪同区间取预约、在岗、区域资格三者交集。预约创建时给定首位陪同人。handover 事件声明旧陪同、新陪同和交接时刻 t；两方均须连续覆盖 [t-2,t+2)，并各自确认同一预约、区域和 t。交接在 t 生效。连续覆盖可由同一陪同人相接且无空隙的多段在岗或资格拼成，跨人拼接必须有有效交接。没有有效交接时，原陪同人的空白时间保持不可通行，后续也不得续接依赖无效交接的声明。同一分钟多次交接、交接成环、倒退时间或重复 ID 内容冲突均拒绝整批。资格撤销可自历史时间起取消自该点及之后的资格；对已发通行回执登记受影响的结论及导致变化的第一处依据，原回执仍保留。

admit 传预约、时间和幂等请求 ID。输出可通行或拒绝及陪同链证据，通行一次只占一个预约的本地名额。重新请求同一 ID 返回首次回执，预约更新通过新请求重新裁定。资格撤销、记录裁定和名额更新按事务快照串行化。coverage 返回最大连续可通行区间和每次实际陪同变化，按时间排序；用扫描事件端点实现，整数区间长度可超过一亿，不逐分钟存储或遍历。

交付代码、README、自生成小样本和测试。覆盖相接的区间合并、恰少一分钟的交接重叠、撤销早期资格使两次后续交接同时失效、旧回执保全、两个并发请求争最后一个名额，以及与逐分钟参考裁定对比的随机小用例。
